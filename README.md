# Розбіжності брендів: еталон і Tabletki.ua

Веб-інструмент порівнює бренди еталонних товарів із брендами зіставлених товарів Tabletki.ua
і формує список розбіжностей для опрацювання. Вивантаження обробляються в браузері й нікуди
не надсилаються.
